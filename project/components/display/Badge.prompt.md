# Badge

Small status pill for labels and states. Seven tones, soft or solid, with an optional dot or icon.

```jsx
<Badge tone="success" dot>Confirmed</Badge>
<Badge tone="brand" icon="calendar">Upcoming</Badge>
<Badge tone="warning" solid>Pending payment</Badge>
```

Tones: `neutral|brand|blush|success|warning|danger|info`. Props: `solid`, `icon`, `dot`, `size`.
