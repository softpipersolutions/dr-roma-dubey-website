# Avatar

Circular avatar — photo when `src` is given, otherwise warm blush initials from `name`. Optional status dot and ring.

```jsx
<Avatar name="Priya Sharma" />
<Avatar src="/photo.jpg" name="Dr. Roma Dubey" size="lg" ring />
<Avatar name="A V" size="sm" status="online" />
```

Sizes: `xs|sm|md|lg|xl` or a number. Props: `src`, `name`, `status`, `ring`.
