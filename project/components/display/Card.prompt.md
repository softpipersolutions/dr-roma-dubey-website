# Card

Warm rounded surface for grouping content. Five variants tune the emphasis; `interactive` adds a hover lift for clickable cards.

```jsx
<Card variant="elevated" padding="lg">…</Card>
<Card variant="soft">Blush-tinted panel</Card>
<Card variant="cream" interactive onClick={…}>Warm clickable card</Card>
```

Variants: `elevated` (shadow, default), `outline`, `soft` (clay-50), `cream`, `ghost`. Padding: `none|sm|md|lg` or a CSS value.
