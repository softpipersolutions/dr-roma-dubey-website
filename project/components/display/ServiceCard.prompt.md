# ServiceCard

The practice's signature marketing card — an icon in a soft chip, a title, a short line, and an optional link. Lifts and the icon tilts on hover.

```jsx
<ServiceCard icon="droplet" title="Pap Smear" description="Designed to detect cervical cancer." href="#" />
<ServiceCard icon="baby" title="Fertility Test" description="Planning for a family?" tone="blush" linkLabel="Explore fertility" href="#" />
```

Props: `icon`, `title`, `description`, `href`, `linkLabel`, `tone` (`brand|blush|sage|dusk`). Lay them out in a responsive grid.
