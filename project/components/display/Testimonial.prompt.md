# Testimonial

A patient review card — terracotta star rating, the quote, and an author row (Avatar + name + role).

```jsx
<Testimonial rating={5}
  quote="Dr. Roma guided me through my entire pregnancy with so much care."
  author="Priya Sharma" role="New mother" />
```

Props: `quote`, `author`, `role`, `avatarSrc`, `rating` (0–5).
