# IconButton

A compact button carrying one icon — toolbars, close buttons, nav actions. Always pass `label` (used for `aria-label` + tooltip).

```jsx
<IconButton icon="x" label="Close" variant="ghost" />
<IconButton icon="bell" label="Notifications" variant="soft" round />
<IconButton icon="arrow-right" label="Next" variant="solid" />
```

Variants: `soft` (blush tint, default), `solid` (terracotta), `outline`, `ghost`. Sizes: `sm | md | lg`. `round` for circular.
