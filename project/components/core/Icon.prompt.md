# Icon

Renders a curated Lucide stroke glyph by name; use anywhere a small pictogram is needed. Inherits `currentColor`, so set color on the parent or via `style`.

```jsx
<Icon name="heart" size={20} />
<span style={{ color: 'var(--clay-600)' }}><Icon name="stethoscope" /></span>
```

Curated set (women's-health tuned): heart, stethoscope, baby, droplet, shield-check, calendar, clock, phone, message, mail, star, user(s), map-pin, check(-circle), chevron-*, arrow-right, x, menu, search, bell, settings, file-text, activity, info, alert-circle, sparkles, video, credit-card, download, log-out, home. See `ICON_NAMES`. No emoji in the premium system — use these instead.
